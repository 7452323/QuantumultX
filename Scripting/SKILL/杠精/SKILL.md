# Purpose

用户想让你"杠"某个话题、帖子、观点或言论时使用此技能。生成符合中文互联网"杠精"文化的回复，风格可选。**基于真实贴吧（英雄联盟吧、穿越火线吧）对线素材精心打磨**，话术模板均提炼自千楼实战贴。

# Instructions

### 方式二：生成可执行的 Scripting 脚本（index.tsx）

当用户想要一个**能在 Scripting App 里运行的互动界面**时，使用以下方式：

1. 创建 `scripts/index.tsx`
2. 使用 Navigation.present() 模式
3. 包含：
   - ✅ 话题输入框
   - ✅ 风格选择（祖安/CF技术杠/电竞粉杠/杠精课代表/阴阳怪气/策划喷子/退坑老鸟）
   - ✅ 生成按钮 + 结果展示
   - ✅ 换一句 + 复制按钮
   - ❌ 不需要最小化功能（除非用户要求）
4. 安装后可当独立应用使用

### 方式三：MCP 工具（高级）

当用户想要杠精能力集成到 MCP 时创建一个 `scripts/main.ts` 通过 `Script.queryParameters` 接收输入并返回结果。

# 杠精语录库（带★为贴吧实战金句）

**万能反问句：**
- "你认真的？"
- "证据呢？出处呢？"
- "你什么段位/分段？"
- "你用过吗就在这说？"
- "笑了"
- "但凡有点常识都不知道..."
- ★ "不是吧不是吧，这年头xxx都能xxx了？"
- ★ "你说是就是吧，你开心就好"

**经典连招 2.0（贴吧实战版）：**
1. 身份压制 → "一看就是xxx玩家/用户"
2. 分段压制 → "你什么分段/段位/冠军？"
3. 情绪输出 → "淦你娘/傻比/菜逼/省省吧"
4. 数据碾压（编的） → "我实测xxx帧/分/秒/段"
5. 反讽收尾 → "你开心就好/啊对对对"
6. 论据否定 → "先问是不是，再问为什么"
7. 转移话题 → "经典岁月史书"
8. 人身攻击 → "A卡/N卡用户吧？难怪说出这种话"
