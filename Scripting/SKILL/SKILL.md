# Purpose

用户想让你"杠"某个话题、帖子、观点或言论时使用此技能。生成符合中文互联网"杠精"文化的回复，风格可选。

# Instructions

## 杠精风格矩阵

| 风格 | 适用场景 | 语气特点 |
|------|----------|----------|
| 🎮 **祖安** | 游戏论坛对线 | 暴躁、直接问候、情绪输出、短句连击 |
| 💻 **CF技术杠** | 电脑配置/游戏性能争论 | 看似有理有据实则抬杠、引用伪技术参数、"我i5比你i9强" |
| 🏀 **电竞粉杠** | LPL/比赛讨论 | 翻旧账、开除粉籍、"你行你上"、数据引战 |
| 🧠 **杠精课代表** | 万能通用 | 永远有角度、永远不服、"你确定吗？""有没有一种可能" |
| 🎭 **阴阳怪气** | 回复任何帖子 | 反话、嘲讽、表情包辅助（脑补版） |

## 调用方式

### 方式一：纯文本生成（无需脚本）
直接用你的语言模型能力生成杠精回复，参考以下模板：

**祖安模板：**
```
就这？xxx就这水平还能xxx？
不是吧不是吧，这年头xxx都能xxx了？
省省吧你，xxx都没搞明白就来指点江山？
```

**CF技术杠模板：**
```
一看就是没用过xxx的，xxx帧数还没我xxx高
我xxx配置玩xxx稳200帧，你这xxx就是优化问题
A卡/N卡用户吧？难怪说出这种话
```

**杠精课代表模板：**
```
你确定吗？据我所知xxxxx
有没有一种可能，xxxxx？
我不是抬杠，但你这个逻辑有问题：xxxxx
先问是不是，再问为什么。实际上xxxxx
```

**阴阳怪气模板：**
```
啊对对对，你说得都对👍
你好懂哦，不像我什么都不会呢~
太厉害了，建议直接xxxxx
```

**电竞粉杠模板：**
```
经典岁月史书，上次xxx的时候你怎么不说话？
xxx的冠军也是你拿的？你什么冠军？
别偷换概念了，xxx和xxx是一回事吗？
```

### 方式二：生成可执行的 Scripting 脚本（index.tsx）

当用户想要一个**能在 Scripting App 里运行的互动界面**时，使用以下方式：

1. 创建 `scripts/index.tsx`
2. 使用 Navigation.present() 模式
3. 包含：
   - ✅ 话题输入框
   - ✅ 风格选择（祖安/CF技术杠/电竞粉杠/杠精课代表/阴阳怪气）
   - ✅ 生成按钮 + 结果展示
   - ❌ 不需要最小化功能（除非用户要求）
4. 安装后可当独立应用使用

### 方式三：MCP 工具（高级）

当用户想要杠精能力集成到 MCP 时创建一个 `scripts/main.ts` 通过 `Script.queryParameters` 接收输入并返回结果。

# 杠精语录库（供参考）

**万能反问句：**
- "你认真的？"
- "证据呢？"
- "出处在哪里？"
- "你用过吗就在这说？"
- "笑了"
- "但凡有点常识都不知道..."

**经典连招：**
1. 质疑前提 → "先问是不是，再问为什么"
2. 转移举证责任 → "你说是就是吧"
3. 人身攻击 → "一看就是xxx玩家"
4. 数据碾压（编的） → "我实测xxx帧/分/秒"
5. 总结收尾 → "你开心就好"

**祖安限定：**
- 以"就这？"开头
- 中间穿插"啊？""不会吧不会吧"
- 结尾用"省省吧"或"洗洗睡"
