个人维护的签到脚本与代理工具配置仓库，适配 **QX** / **Surge** / **Loon** 三平台。

脚本基于 [chavyleung/Env.js](https://github.com/chavyleung/Scripts) 框架，微信读书相关脚本来源：[TomCatXue/MyCookieCenter](https://github.com/TomCatXue/MyCookieCenter)

---

## 功能

| | 功能 | 说明 |
|:---:|---|---|
| 🔰 | 签到脚本 | 阅读领卡、连续打卡、每日签到，自动领取奖励 |
| 📦 | 三平台同步 | Surge 模块 · Loon 插件 · QX 脚本 · BoxJS 订阅 |
| 🛡️ | 防强更净化 | 微信读书弹窗拦截，保持 App 原生体验 |
