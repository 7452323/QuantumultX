签到脚本 · App 解锁 · Surge 模块 · Loon 插件 · BoxJS 订阅 · 油猴脚本

适配 **QX** / **Surge** / **Loon** 三平台，脚本基于 [chavyleung/Env.js](https://github.com/chavyleung/Scripts) 框架。

微信读书相关脚本来源：[TomCatXue/MyCookieCenter](https://github.com/TomCatXue/MyCookieCenter)

---

## 目录

| 目录 | 内容 |
|:---|:---|
| `task/` | 签到脚本 — Readify 深读、微信读书、HDHive 影巢、酷我音乐、色花堂、书香门第 |
| `task/Reading/` | 微信读书全功能自动化 — 领卡、翻牌、限免、Cookie 抓取（来源: TomCatXue） |
| `script/` | App 解锁与功能脚本 — Epub、Fotoz、Hireader、Retouch、Shuiyinbao 等 20+ App |
| `script/ReadingAd/` | 微信读书防强更净化（来源: TomCatXue） |
| `script/pornography/` | 解锁脚本 — lzlukvca（Surge/Loon/QX 三平台） |
| `script/Frameworks/` | BoxJS 订阅 · checkin 框架 · unlock 框架 |
| `surge/` | Surge 模块 — 30+ App 解锁模块 |
| `surge/script/` | Surge 签到模块 — Readify、微信读书、防强更 |
| `surge/scripting/` | Surge 通知脚本 |
| `loon/` | Loon 插件 — 40+ App 解锁插件与 .lpx 布局文件 |
| `loon/Scrip/` | Loon 签到插件 — HDHive、Readify、微信读书 |
| `Javdb/` | JavDB 番号查询工具 — Node.js 脚本 + 数据库 |
| `Userscripts/` | 油猴脚本 |
| `Python/` | Python 工具脚本 |
| `Rule/` | 分流规则 |
| `icon/` | BoxJS 图标资源 |
