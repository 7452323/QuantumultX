## 简介

个人维护的 QuantumultX 配置仓库，涵盖签到脚本、Surge 模块、Loon 插件及 BoxJS 订阅。脚本基于 [chavyleung/Env.js](https://github.com/chavyleung/Scripts) 框架，支持三平台运行。

微信读书全功能自动化与防强更净化脚本来源：[TomCatXue/MyCookieCenter](https://github.com/TomCatXue/MyCookieCenter)

---

## 功能

| | |
|:---:|:---|
| 🔰 | **签到脚本** — 阅读领卡、连续打卡、每日签到 |
| 📦 | **三平台同步** — Surge 模块、Loon 插件、QX 脚本、BoxJS 订阅 |
| 🛡️ | **防强更净化** — 微信读书弹窗拦截 |
